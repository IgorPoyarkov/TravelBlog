#  TravelBlog — Блог для путешественников

Фронтенд-приложение на React + TypeScript + React Query + Zod + Zustand, работающее с локальным REST-бэкендом на `json-server-auth`.

##  Инструкция по запуску проекта

Для успешной проверки работы и функционирования всех фич (авторизация, профиль, добавление постов и комментариев), проект необходимо запустить в режиме одновременной работы фронтенда и локальной базы данных.

1. Установите все зависимости проекта:
   ```bash
   npm install
   ```

2. Запустите проект (автоматически поднимет Vite на 5173 порту и базу данных из файла `db.json` на 3000 порту):
   ```bash
   npm start
   ```

*Примечание: Если порты 3000 или 5173 на вашем компьютере заняты, Vite и json-server могут автоматически переключиться на соседние порты.*
